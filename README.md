# ESP32 Wi-Fi Smart-Lock

## 概要

このプロジェクトは、安価で高性能なマイクロコントローラ「ESP32」を心臓部に、自作のスマートロックを製作することを目的としています。

サーボモーターをドアの施錠・解錠を行う物理的なアクチュエータ（動力源）として利用し、操作方法として「室内側からの物理スイッチ操作」と「Wi-Fi経由での遠隔操作」の2種類を提供します。これにより、手軽な利便性と、スマートフォンやPCからの遠隔管理能力を両立させます。

ロックの状態はLEDで視覚的に確認できるため、現在の状態が一目瞭然です。DIY電子工作を通じて、スマートホームの基本的な仕組みを学びながら、実用的なデバイスを作り上げることを目指します。

## インストール（セットアップ）

### 1. 必要なもの（ハードウェア）

各コンポーネントの役割を理解することで、組み立てがスムーズになります。

* **ESP32 開発ボード:** プロジェクト全体の頭脳。Wi-Fi機能を内蔵しており、ネットワーク通信と全体の制御を担います。
* **サーボモーター:** 鍵やドアのデッドボルトを物理的に動かすための「筋肉」となる部品です。指定した角度に動く特性を利用して、施錠・解錠の動作を実現します。
* **タクトスイッチ（押しボタン）:** ユーザーが手元で操作するための入力装置です。室内側からの施錠・解錠を想定しています。
* **LED:** ロックの状態（例：施錠中は点灯、解錠中は消灯）を色や光で直感的に知らせるインジケーターです。
* **その他:** ブレッドボード、ジャンパーワイヤーなど、各部品を電気的に正しく接続するための基本的な電子工作部品。

### 2. 必要なもの（ソフトウェア・ライブラリ）

プログラミング環境としてArduino IDEを使用します。

* **Arduino IDE:** ESP32ボードパッケージを事前にインストールし、ESP32開発ボードへの書き込みができるようにしておいてください。
* **必要なライブラリ:** Arduino IDEのライブラリマネージャから以下のものをインストールします。
    * `WiFi.h`: ESP32のWi-Fi機能を利用するために必須の標準ライブラリです。
    * `ESP32Servo.h`: ESP32でサーボモーターを精密に制御するために使用します。

### 3. ハードウェアの配線

スケッチ（プログラムコード）に記載されているピン定義に従い、各コンポーネントをESP32に接続します。

| コンポーネント | ESP32 ピン | 備考 |
| :--- | :--- | :--- |
| サーボモーター（信号線） | **GPIO 14** | 電源はESP32の`Vin`と`GND`に接続します。 |
| LED | **GPIO 17** | 電流制限抵抗（220Ω〜330Ω程度）を介して接続します。 |
| タクトスイッチ | **GPIO 19** | スイッチのもう一方の足は`GND`に接続します。 |

### 4. Arduinoコードの設定

プログラムを書き込む前に、ご自身の環境に合わせてコードを一部編集する必要があります。

1.  Arduino IDEでプロジェクトのスケッチファイルを開きます。
2.  冒頭にある以下の定数をご自身のWi-Fi環境に合わせて書き換えます。
    ```cpp
    const char* ssid     = "あなたのWi-FiのSSID";
    const char* password = "あなたのWi-Fiのパスワード";
    ```

## 使い方

### 1. プログラムの書き込みと実行

1.  Arduino IDEの「ツール」メニューで、使用するボードを「ESP32 Dev Module」などに設定します。
2.  PCとESP32をUSBケーブルで接続し、正しいシリアルポートを選択します。
3.  IDEの書き込みボタン（→）をクリックし、プログラムをESP32に転送します。
4.  書き込み後、IDEのシリアルモニタを開きます（通信速度: 115200）。ESP32がWi-Fiに接続し、割り当てられたIPアドレス（例: `192.168.1.10`）が表示されるのを確認します。このIPアドレスは遠隔操作で必要になるため、控えておいてください。

### 2. 操作方法

このスマートロックには、状況に応じて使い分けられる2つの操作方法があります。

* **物理スイッチによる直接操作:**

    * 本体に接続されたタクトスイッチを押すたびに、サーボモーターが「施錠位置」と「解錠位置」の間を交互に動きます。室内からの操作に便利です。
    * 操作と連動して、LEDが現在の状態を示します。

* **ウェブブラウザによる遠隔操作:**

    1.  スマートフォンやPCを、ESP32と同じWi-Fiネットワークに接続します。
    2.  ウェブブラウザを開き、アドレスバーに先ほど控えたESP32のIPアドレスを入力してアクセスします。
    3.  画面に「unlock（解錠）」と「lock（施錠）」の2つのシンプルなリンクが表示されます。
    4.  これらのリンクをタップまたはクリックすることで、どこからでもロックの状態を遠隔で切り替えることができます。

## コードの主な仕組み

* **`setup()`関数:**

    * プログラム起動時に一度だけ実行される初期化処理です。
    * サーボモーター、LED、スイッチを接続した各GPIOピンを入出力モードに設定します。
    * 指定されたSSIDとパスワードでWi-Fiへの接続を開始します。
    * Wi-Fi接続が完了すると、IPアドレスを取得してシリアルモニタに出力し、外部からのHTTPリクエストを受け付けるためのウェブサーバーを起動します。

* **`loop()`関数:**

    * 電源が入っている間、常に繰り返し実行されるメインの処理です。
    * **スイッチの監視:** `getSw()`関数を呼び出し、物理スイッチが「押された瞬間」を検知します。長押しやチャタリング（微細な振動）による誤作動を防ぎ、クリーンな入力のみを受け取ります。
    * **ウェブサーバーの待機:** `server.available()`を使い、Wi-Fi経由でウェブブラウザなどからのアクセスがないか常に監視しています。アクセスがあると、そのクライアントとの通信を開始します。
    * **リクエスト処理と応答:** クライアントからのHTTPリクエストを1行ずつ読み取ります。リクエストの末尾が`GET /H`であれば解錠、`GET /L`であれば施錠の動作をそれぞれ実行します。リクエストの種類に関わらず、操作用のリンクを含む簡単なHTMLページをクライアント（ブラウザ）に返信します。
